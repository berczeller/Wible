# Changelog

All notable changes to this project are documented here. The format follows Keep a Changelog and the project uses Semantic Versioning.

## [0.1.0] - 2026-11-21

### Added
- Draw tool to place curve points on surfaces or in the air, with a live preview
- Right-click on a curve while drawing to add a point to it
- Catenary gravity with Tension, Weight and Length per span
- Live rope physics with Stiffness and Damping, no timeline needed
- Draping and collisions with nearby objects or a chosen collection
- Point handles to reshape curves live; moving, rotating or scaling a curve keeps its rope length
- Depth, Resolution, Radial Resolution and Fill Caps
- Save as Curve and Save as Mesh, plus Edit Curve to reopen saved ones
- Mesh output with UVs for the side and caps, smooth or flat shading, and hard or beveled cap edges
- Trim sheet slots with texel density and padding
- Per-curve history bar
- Sidebar tab and a `Shift+Alt+X` popup
